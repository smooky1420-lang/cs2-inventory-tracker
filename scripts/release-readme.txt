CS2 Inventory Tracker
=====================

1. Open config.env in Notepad.
2. Set STEAM_ACCOUNT_NAME and STEAM_PASSWORD.
   If the password contains #, keep the double quotes around it.
3. Double-click CS2InventoryTracker.exe.
4. Keep the black console window open. The app is at http://localhost:3000

After you click Sync Steam, a data folder appears next to the exe
(inventory, buy prices, and Steam login cache).

Windows may warn that the app is unsigned. Choose More info -> Run anyway.
